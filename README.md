# element115wireless.com

Static homepage for Element 115 Wireless LLC. Single file: `index.html` (no build step, no dependencies).

The hero is an interactive WebGL2 scene (atom with a 115-proton nucleus). Browsers without WebGL2 fall back to a 2D canvas version.

## Before launch

- The contact form is not wired up yet: connect it to a form handler or CRM.
- Point the element115wireless.com DNS at the chosen host (GitHub Pages, Netlify, etc.).
